## Slide 6: Security, Accuracy & Compliance
**Title:** Enterprise-Grade Security for Banking

**Bullet Points:**
- **100% On-Premise AI:** Powered by the local Llama 8B model via Ollama. No data is sent to external or cloud APIs, ensuring complete data privacy.
- **Zero Hallucination Guarantee:** Unlike public AI (like ChatGPT), our agent cannot "guess" financial numbers. It only formats the real data retrieved from the database.
- **Role-Based Access Control (RBAC):** Users only see the data marts they are explicitly authorized to access by an Admin.
- **Strict Data Isolation:** AI processing is separated from core banking databases using dedicated, read-only data marts.
- **Comprehensive Audit Logs:** Every login, question asked, and data table accessed is tracked and logged with IP addresses for compliance.
